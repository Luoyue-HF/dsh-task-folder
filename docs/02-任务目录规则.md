# 02 · 任务目录规则

## 命名格式

```
<月日>_<任务名>/
```

- 日期取**本地日期**，`月-日`，不带年份，如 `10-27`。
- 任务名默认来自会话的首条消息，标题生成后会自动改成标题名。
- 任务名最长 `maxNameChars`（默认 **24** 字符），超长**按码点截断**——emoji 不会被切成半个。
- 自动清理的字符：`\ / : * ? " < > |` 以及控制字符；中文、emoji 保留。

## 同名冲突：`~2` 后缀

同一天建出同名目录时，自动追加 `~2`、`~3`，最多重试 10000 次后明确报错：

```
10-27_季度汇报PPT/
10-27_季度汇报PPT ~2/     ← 第二个同名任务
```

用 `~` 而不是 `_` 是有意的：你的任务名里可能本来就有 `_数字`（如 `方案_2`），用 `_2` 当后缀会与它混淆，`find` / `reuse` 时无法区分。

占位是**原子 `mkdir`**（非 recursive）+ `EEXIST` 重试，不存在"先探测再创建"的竞态窗口。

## 标记文件 `.dsh-task-folder`

任务目录直接建在工作区根下，与用户自己的目录混在一起。为了区分，本插件建仓时在目录里写一个**空的隐藏标记文件**：

```
10-27_季度汇报PPT/
├── 季度汇报.pptx
└── .dsh-task-folder    ← 本插件的标记（存在与否决定扫描时认不认它）
```

扫描目录（`list` / `reuse` / 自动分配判断）时，只认两类：

1. **带 `.dsh-task-folder` 标记**的目录；
2. **旧格式目录** `2026-10-26_07_任务名`（插件 0.1.x 时期生成、带序号的目录，必然是本插件建的，无需标记也认）。

你**自己手动建的**同名格式目录（比如 `10-27_我的清单`）没有标记，不会被误认、不会被当成「已存在的任务」抢走，也不会出现在 `list` 里。

> 如果配置了 `subdir`（例如 `subdir: 产物`），任务目录集中在 `<工作区>/产物/` 下，整个子目录由插件独占，此时不再依赖标记文件。

## 空目录回收

任务目录变空（不含标记文件本身）后，会在以下三处被自动回收：

- 会话 `agent/disposed` 时
- `task_folder action=reuse` 时（复用前先清掉别的空目录）
- `task_folder action=new` 时

有内容的目录永远不会被自动删除。

## 目录落在哪里

| `rootMode` | `subdir` | 结果 |
|---|---|---|
| `workspace`（默认） | `''`（默认） | `<工作区>/<月日>_<任务名>/`，靠标记文件区分 |
| `workspace` | `产物` | `<工作区>/产物/<月日>_<任务名>/`，子目录独占 |
| `custom` | — | 用 `rootPath` 指定的绝对路径；留空回退 `~/Documents/DSH-产物` |
