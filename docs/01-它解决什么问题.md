# 01 · 它解决什么问题

> 适用对象：第一次接触 dsh-task-folder 的人。

## 痛点

在 DeepSeek Harness（DSH）里跑对话久了，工作区根目录会长成这样：

```
DSH工作区/
├── 汇报.pptx
├── 方向稿a.pptx
├── 数据.xlsx
├── _fetch_demo.py
├── demo_officecli/
├── assets_food/
├── 竞品调研.md
└── ……各种会话的产物全散在一起
```

所有会话的产物默认都写在同一个工作区根下。时间一长，谁也分不清哪个文件属于哪次任务，换会话续做还要靠人肉记路径。

## 解决方式

dsh-task-folder 给**每一个任务**自动分配一个专属目录，并把会话的工作目录切过去：

```
DSH工作区/
├── 10-27_季度汇报PPT/      ← 这次对话的所有产物都在这里
├── 10-27_竞品调研/
├── 10-28_网站改版/
└── 论文与文献/              ← 你自己建的目录，插件不碰
```

## 核心能力一览

| 能力 | 说明 |
|---|---|
| 新会话自动分目录 | 第一次真正跑任务时建 `<月日>_<任务名>/`，并把会话 cwd 切过去 |
| 换会话续同一任务 | `task_folder action=reuse` 或说一句「继续做 xxx」即切回已有目录 |
| 自动命名 / 自动改名 | 先按首条消息命名，标题生成后再改成更贴切的标题名（90 秒窗口内） |
| 续用会话不新建 | resume / fork / clear / compact 都继承原目录 |
| 标记文件防误认 | 目录内写入 `.dsh-task-folder`，与用户自建目录区分开 |
| 空目录自动回收 | 任务做完目录空了会回收，有内容的不会动 |
| 老会话自动收编 | 升级插件前就在用的会话，默认也会被收编（见 [05-旧会话与升级行为](05-旧会话与升级行为.md)） |

## 它不会做什么

- 不会给子代理（subagent）、派生会话开目录——否则一个任务会炸出十几个空文件夹。
- 不会替你归档、删除有内容的目录。
- 不会追溯**已结束**的历史会话。
